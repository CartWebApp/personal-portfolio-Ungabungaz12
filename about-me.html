About Me

Future High School Graduate

I am a junior at my current school, Edison High School. With the year nearing its close at the time of writing this, I am on my way to graduate while maintaning a above 3.2 average GPA

Web Development Experience

I took the Web Application Development course at the Center for Advanced Research and Technology (CART) during the 2025-2026 school year. This class taught me about how to develop websites such as the one you are reading this on right now!

Year in Review

The Baseline

At the start of my CART school year, I didnt know very much about web development. I knew other concepts like C# and the general programming workflow, but not much more than that. Pushing a website to the web without using something like Google Sites seemed unattainable then.

Inital Hurdles

The first project that truly challenged my existing view was the Paw-Pal Project. The lo-fi, Hi-fi, and website creation process was actually really difficult at first. Mostly because I had barely any ideas. The website part was difficult as well, writing almost, if not all of the HTML and CSS by hand showed me just how much work went into it. You could spend more than a few days on a single page of the website

Skill Synthesis

The moment when everything truly began to click for me was during the small projects like CSS Zombies and especially CSS Zen Garden.

The Power of Persistence

I remember there was a specific bug in my CSS Zen Garden design where the post-it notes wouldn't move when I hovered over them no matter what I did. Solving the problem (The animation name was wrong) really boosted my morale.

Habits of the Mind

I remember for the CSS Zen Garden project I actually got some suggestions from those sitting next to me for my design, and what I could do for the CSS code as well, demonstrating communication and collaboration.

Advanced Logic

Initially, Javascript was very jarring from HTML and CSS. It almost seemed alien in the way it was structured, but over time, it caught on rather quickly.

The Personal Website

This final project represents the culmination of all of my work up to this point. It contains both the HTML and CSS structuring principles I learned from the start of the year, and the Javascript I learned at the end.
